# Дорожная карта развития SCADA-редактора

> Основана на трёхстороннем аудите кода (store-логика, канвас/UX, сериализация/рантайм/бэкенд),
> проведённом 12.07.2026. Цель — довести редактор до уровня производственных SCADA-систем
> (Ignition, WinCC, AVEVA InTouch). Легенда: ✅ выполнено · 🔶 частично · ⬜ не начато.

---

## Итог аудита (кратко)

| Тема | Вывод |
|---|---|
| Целостность данных | Критические баги: порча компонентов при группировке/разгруппировке, undo «протекает» между сценами, потеря тегов/скриптов при save→load, битый роут свойств |
| Производительность канваса | Stage 5000×5000 (~100–800 МБ, не работал в Safari), полный ре-рендер сцены на каждый тик пана/зума, запись в стор на каждый пиксель ресайза, O(n²) на горячем пути |
| UX-паритет редактора | Нет мульти-drag, числовых X/Y/W/H, поворота, z-order, выравнивания, zoom-панели |
| SCADA-ядро | **Рантайма нет вообще**: WebSocket отключён, `bindings` — мёртвые данные, скрипты — инертные блобы. Живой мнемосхемы — ключевого свойства SCADA — не существует |
| Надёжность/мультиюзер | `version: 0` захардкожен (last-write-wins), нет блокировок сцен, нет dirty-индикатора и `beforeunload`, прокси глотают статусы |

## Фаза 1 — Критические баги целостности данных ✅ ВЫПОЛНЕНО

| Статус | Что | Где |
|---|---|---|
| ✅ | `groupSelected`: fast-path учитывает `composition`, для компонентов вызывает `resplitContainer` — примитивы больше не сериализуются как вложенные компоненты | `useEditorStore.ts` |
| ✅ | `ungroupSelected`: rendered-координаты через `shiftElementPositions` (base + overrides), члены `composition` реparent'ятся/выделяются/вливаются в прародителя по роли | `useEditorStore.ts` |
| ✅ | Гигиена undo: `temporal.clear()` в `loadScene`/`createScene`/`setCurrentProject` — Ctrl+Z не «воскрешает» элементы другой сцены (и не плодит дубли с `id:null`) | `useEditorStore.ts` |
| ✅ | `addTags`/`editProperty` обёрнуты в `temporal.pause()/resume()` — серверные мутации вне истории undo | `useEditorStore.ts` |
| ✅ | Создан роут `PUT /api/editor/tags/[id]` — редактирование свойства работает (раньше 404) | `src/app/api/editor/tags/[id]/route.ts` |
| ✅ | Round-trip: `scripts`/`bindings`/`properties` примитивов в `composition` запекаются и восстанавливаются (проверено headless-тестом 12/12 PASS) | `buildComponentTree.ts`, `transformElements.ts` |
| ✅ | `deleteSelectedElement`: откат при ошибке сервера, чистка `children`/`composition` родителя, `activeGroupKey`, пересчёт рамок | `useEditorStore.ts` |
| ✅ | `POST /api/editor/scene` пробрасывает реальный статус бэкенда (раньше всегда 201) | `scene/route.ts` |
| ✅ | Мелочи: console.log-и, распространение состояний на complex-компоненты, фолбэк `"undefined"` parentKey | `useEditorStore.ts` |

**Известное ограничение** (перенесено в Фазу 5): undo после успешного серверного DELETE
восстанавливает элементы со старыми `id`, которых нет на сервере — нужен контракт версий/upsert.

## Фаза 4 — Рантайм (живые данные) ⬜ НЕ НАЧАТО — ядро SCADA

Сейчас продукт — только design-time редактор. Для «настоящей SCADA» нужно:

| Статус | Что |
|---|---|
| ⬜ | **Режим просмотра/рантайма** (read-only, без ручек редактирования) — роут или переключатель |
| ⬜ | Включить WebSocket (`WebSocketProvider` — `activate()` закомментирован; `wsClient` захардкожен на `localhost:8080`) и подписку на значения тегов |
| ⬜ | **Движок биндингов**: значение тега → переключение состояния (`states` по имени) / прямое изменение визуального свойства. Механизм `states`+`overrides` уже готов — не хватает только драйвера данных |
| ⬜ | UI создания биндингов (`bindings` сейчас мёртвые данные: никто не создаёт и не применяет) |
| ⬜ | Прояснить контракт исполнения скриптов с бэкендом (Java-блобы: где исполняются, песочница, валидация) |

## Фаза 5 — Надёжность и многопользовательность ⬜ НЕ НАЧАТО

| Статус | Что |
|---|---|
| ⬜ | Optimistic concurrency: реальный `version` вместо захардкоженного 0 (`buildComponentTree.ts:96`), обработка 409, reload-on-conflict |
| ⬜ | Блокировка сцен при редактировании (переиспользовать lock/unlock API области каналов + `sendBeacon` на unload) |
| ⬜ | Dirty-индикатор («есть несохранённые изменения») + `beforeunload` (сейчас теряется до 60с работы между тиками автосейва) |
| ⬜ | Решить undo-vs-DELETE (восстановление со stale id) — вместе с контрактом версий |
| ⬜ | Прокси: GET-роуты пробрасывают статус бэкенда вместо `throw` → 500 (клиент не отличает 403 от 500) |
| ⬜ | Битый JSON в `image` при загрузке → предупреждение, а не молчаливый пустой элемент 80×80 |
| ⬜ | Объединить два несогласованных сейв-лока (`saveInFlight` в сторе + `savingRef` в `useAutoSaveScene`) |
| ⬜ | Палитра: предупреждать, что tag-свойства срезаются при сохранении шаблона |
| ⬜ | Подсказка «сначала сохраните сцену» при добавлении свойства к несохранённому элементу (`id:null` — сейчас молча ничего) |
| ⬜ | Персист камеры (последний вьюпорт сцены) |
