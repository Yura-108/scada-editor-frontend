# Ручная проверка

Автотестов нет, раннер не настроен — только `npm run dev`.

### Доступ и авторизация
1. В приватном окне открыть `/log` → редирект на `/login`.
2. Неверный пароль → остаёмся на `/login`, видно сообщение бэкенда, редиректа нет.
   Верный → `/channels`. Регистрация с занятым логином → сообщение, не редирект.
3. В логах сервера при входе нет строки `Login data:` с токеном.

### Undo и хоткеи
4. Подвигать элементы → «Сохранить» → **Ctrl+Z работает**. Повторить после
   срабатывания автосохранения (10 мин или временно уменьшить константу).
5. Выделить 5 элементов, перетащить, Ctrl+Z **один раз** → возвращаются все 5.
6. Открыть модалку, кликнуть по её кнопке (не в поле ввода), нажать Delete →
   элементы на холсте **не** удаляются. Escape закрывает только модалку.
7. Открыть редактор скриптов, набрать код, Ctrl+Z → отменяется **текст**, не схема.

### Целостность данных
8. Открыть два устройства, изменить параметр только у первого, сохранить →
   в запрос уходят изменения **только первого**.
9. Остановить бэкенд: сохранить шаблон палитры → тост об **ошибке**; удалить
   параметр / заблокировать узел → тост об ошибке, а не тишина.
10. Ctrl+C, затем Ctrl+V дважды → две копии **со смещением**.
11. Разгруппировать ранее сохранённую группу → «Сохранить» → группа **не**
    возвращается после перезагрузки.
12. Вставить, затем Ctrl+Z → панель свойств и кнопки группировки согласованы.

### Обратная связь
13. Кнопка «Сохранить»: спиннер во время сохранения, повторный клик не проходит,
    рядом со сценой — «сохранено в HH:MM».
14. Изменить схему → закрыть вкладку → предупреждение браузера.
15. Undo/redo в тулбаре активны только когда есть что отменять.
16. «Записать рецепт в ПЛК» → подтверждение появляется **поверх** модалки рецепта,
    сама модалка не пропадает; отмена не запускает запись.
17. Удаление категории палитры и шаблона спрашивают подтверждение.
18. `/log` до выбора периода → «Выберите период»; поиск без совпадений → отдельное
    сообщение, а не пустая таблица.

### Внешний вид
19. Кнопка «Сохранить» цветная; модалки и меню появляются с анимацией.
20. Проверить **светлую** тему: тулбар, поиск в палитре, `/log`, заголовок
    в `/channels`.
21. В тёмной теме навести курсор на пункты навигации: неактивные серые, активный
    выделен. Переключатель темы при системной тёмной теме показывает правильную
    иконку и срабатывает с первого клика.
22. `/` → редирект; несуществующий URL → 404, «На главную» ведёт на рабочую страницу.

### Взаимодействие с холстом
23. Протянуть рамку и отпустить мышь **над боковой панелью** → рамка исчезает.
24. Ctrl+клик по выделенному элементу → снимает выделение.
25. В поле «X» стереть значение и набрать новое → элемент не прыгает в ноль;
    в истории одна запись.
26. Зум и панорамирование колесом **в Firefox**.
27. «Вооружить» элемент палитры, провести мышью над существующими → прицел остаётся.
28. Контекстное меню: «Добавить свойство» на несохранённом элементе неактивно;
    закрывается по Escape и клику вне; «Удалить» действительно удаляет.

### Фундамент (раздел C)
29. Открыть любую модалку → **фон не прокручивается** колесом мыши; страница
    при открытии не дёргается вбок (место под полосу прокрутки зарезервировано).
30. В тёмной теме пройти `/channels`: дерево устройств, карточки параметров,
    контекстное меню по ПКМ, стартовое меню выбора площадок; `/login`
    и `/register` — карточка, поля, сообщение об ошибке.
31. `/login` и `/register` — **шапки с навигацией нет**, есть логотип и
    переключатель темы. После входа шапка появляется.
32. Ни на одной странице нет вертикальной полосы прокрутки «на 64px»
    при коротком содержимом.
33. Открыть «Записать рецепт в ПЛК» → подтверждение поверх модалки; открыть
    `Select` внутри модалки → список поверх неё; контекстное меню холста
    поверх панелей.
34. Открыть детали лога с длинным payload → окно не выходит за края,
    прокручивается внутри, кнопка «Закрыть» доступна.
35. «Добавить компонент» / «Переместить в группу»: Tab не уводит фокус за
    пределы окна, Escape закрывает, клик по затемнению закрывает.
36. Остановить бэкенд (или заставить его вернуть 4xx): сохранение сцены,
    загрузка палитры, добавление параметра → в тосте **сообщение бэкенда**,
    а не кусок HTML-страницы ошибки.

### Доступность (раздел D)
37. Пройти редактор одним Tab: фокус **видно** на каждой остановке; вкладки
    переключаются стрелками; панель слоёв — одна остановка Tab, дальше ↑↓ по
    строкам, →/← раскрывают и сворачивают, Enter выделяет.
38. Встать на ручку между панелью и холстом → стрелки меняют ширину, Home/End —
    крайние значения, Enter сворачивает панель.
39. Свернуть обе боковые панели → Tab **не** останавливается на невидимых
    кнопках сворачивания.
40. В дереве устройств встать на узел, нажать Shift+F10 → открылось меню, ↑↓
    ходят по пунктам, Escape закрывает и **возвращает фокус на тот же узел**.
41. Сузить окно до мобильной ширины → появляется бургер-меню, разделы доступны.
42. `/login`: менеджер паролей предлагает сохранённую пару; кнопка «глаза»
    объявляется как «Показать пароль».
43. Скринридером: элемент палитры объявляется как кнопка с состоянием «нажата»
    после «вооружения»; активный пункт навигации — как текущая страница.

### Тексты и стиль (раздел E)
44. Выделить элемент → заголовок панели свойств по-русски («Свойства: Кнопка»),
    вид заголовка совпадает с «Слоями» и «Рецептами».
45. Двойной клик по тексту на холсте, изменить, Escape → правка **отменена**;
    то же, но клик мимо → сохранена.
46. Выделить круг → в «Геометрии» поле «Радиус» (не Ширина/Высота), ввод меняет
    фигуру. У линии, многоугольника и текста поля «Поворот°» нет.
47. Протянуть рамку выделения поверх выделенного элемента → синий **один**.
    Проверить в обеих темах.
48. Подвигать край боковой панели, переключить вкладку, свернуть панель →
    перезагрузить: ширина, свёрнутость и вкладка восстановились.
49. В консоли браузера при работе монитора нет потока `[monitor:ws]` и дампов
    событий (продакшен-сборка).
50. Модалки: «Отмена» в светлой теме при наведении светлеет, а не темнеет;
    заблокированная главная кнопка выглядит одинаково во всех модалках.
51. Несуществующий URL → сдержанная страница 404, обе кнопки читаемы в обеих темах.
