## CLICK & INTERACTION FLOW

Standard Pattern (all shapes):
1. Click element
2. Handler calls selectMultiple([id]) or selectMultiple([...selectedIds, id])
3. Store updates selectedIds
4. Component re-renders with isSelected = selectedIds.includes(el.key)
5. Visual feedback: stroke color/width change

Modifiers:
- Shift+Click: Add to selection (selectMultiple([...selectedIds, el.key]))
- Ctrl+Click: Add to selection (same behavior)
- Plain Click: Replace selection (selectMultiple([el.key]))
- Background Click: Clear selection (selectMultiple([]))

Special Cases:
- Group center circle (line 716-719): e.cancelBubble = true prevents parent propagation
- Context menu (line 400-431): Selects element BEFORE showing menu
- Drag select rectangle (line 310-372): Adds all intersecting elements

## GROUP OPERATIONS

CREATE GROUP (groupSelected - lines 668-802):
1. Validate: selectedIds.length >= 2
2. Filter to top-level (not nested in other selected)
3. Compute union bounds with 24px padding
4. Transform children to group-local coordinates
5. Create GroupElement with computed position/size
6. Update elements array
7. Select the new group

Special case (lines 691-715):
- If adding simple elements to existing group, just add to children and re-layout

UNGROUP (ungroupSelected - lines 803-879):
1. Find all selected groups
2. For each group:
   - Adjust child coordinates: x += groupX, y += groupY
   - Change parentKey to grandparent
   - Update parent's children list
3. Remove groups from elements array
4. Select freed children

MOVE TO GROUP (moveElementToGroup - lines 880-938):
1. Add element to target group's children
2. Remove from old parent's children if different
3. Call layoutGroupFromBounds() on target group
4. Call layoutGroupFromBounds() on old parent if has remaining children

## GROUP LAYOUT SYSTEM

Bounds Calculation:
- snapshotBounds(): Maps element key → bounds (minX, minY, maxX, maxY)
- unionBounds(): Finds min/max across all bounds, adds 24px padding

Coordinate Systems:
- Elements store BOTH absolute (world) position and relative (parent-local)
- Group children have parentKey pointing to group UUID
- elementToGroupLocal(): Transforms absolute position to group-local
- Preserves visual position on canvas during transformation

Position Overrides:
- elementToGroupLocal() clears position overrides from component states
- Keeps style overrides (color, opacity, etc.)

## COMPONENT STATE SYSTEM

Overview:
- Each element can have multiple ComponentState objects
- Each state has id, name, overrides, isDefault flag
- currentComponentStateByElementKey maps element key → active state ID

Cascade to Children:
- Setting state on group propagates matching-named state to children
- If child doesn't have matching state, uses default state
- getDescendantKeys() recursively finds all descendants

Used in:
- PropertiesPanel to determine which overrides to display
- Canvas rendering to apply visual overrides

## KEY OBSERVATIONS

1. Selection NOT persisted in undo/redo
2. No active group rename - auto-generated labels like "Group (3)"
3. Fully supports nested groups (recursive rendering)
4. Shift+Ctrl both add to selection (no difference)
5. Drag select is additive (adds to existing selection)
6. Group center circle click allows selecting group when inside it
7. No keyboard shortcuts for Group/Ungroup (only toolbar buttons)
8. Device tree completely separate from canvas (different store, UI)
9. Element key = UUID, used for all lookups and state management
10. Server ID = number, used for persistence to backend
11. Position overrides cleared when grouping to avoid conflicts
12. Group padding = 24px (constant, not configurable)

## INTERACTION PATTERNS SUMMARY

Canvas Element Selection:
- Click → selectMultiple([id])
- Shift/Ctrl+Click → selectMultiple([...selectedIds, id])
- Background Click → selectMultiple([])
- Drag Rectangle → selectMultiple([...selectedIds, ...intersecting])
- Right-Click → selectMultiple([id]) then show menu

Group Operations:
- Select 2+ elements → Click "Group" button → groupSelected()
- Select 1+ groups → Click "Ungroup" button → ungroupSelected()
- Right-click element → "Move to group" → MoveToGroupModal

Device Tree Selection:
- Single click → setState({selectedDevice: key})
- Right-click → select then show menu

Visual Feedback:
- Selected elements: blue stroke, different width
- Selected groups: blue circle at center
- Component states: visual overrides applied from active state
- Properties panel: shown only if 1 element selected
