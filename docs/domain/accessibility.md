# Доступность рабочих разделов

После первого Tab ссылка «К содержимому» переносит фокус на основную часть
раздела. Верхнее меню объявляется как «Разделы». На узком экране заголовок
раздела остаётся доступен экранному диктору.

В базе каналов «Площадку» и «Проекты базы каналов» можно открыть клавишей Enter.
В списке стрелки, Home и End перемещают фокус, а пробел или Enter меняют выбор.
Стрелка вниз из строки поиска переводит фокус в список. Esc закрывает список и
возвращает фокус на кнопку.

Для локальной проверки выполните `npx playwright install --only-shell chromium`,
`npm run build`, затем `npm run test:a11y`. Проверка работает на локальной
production-сборке с тестовыми ответами API в Chromium. Она проверяет восемь
рабочих разделов в светлой и тёмной теме, раскрытые списки базы каналов, вкладки
редактора и контраст элементов из #29. В GitHub Actions она входит в
`Frontend checks`.
