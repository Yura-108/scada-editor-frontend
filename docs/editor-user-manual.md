# Руководство пользователя: редактор SCADA-схем

Документ описывает работу в разделе **«Редактор схем»** (`/editor`) — основном инструменте
для создания мнемосхем (визуальных схем технологических процессов). Разделы «Монитор»,
«База каналов» и «Логирование» в этом руководстве не рассматриваются.

## 1. Общее описание

Редактор схем — инструмент для построения мнемосхем: на холст перетаскиваются элементы
(линии, кнопки, индикаторы, графики и т.д.), им задаётся внешний вид, состояния
(«Норма», «Авария» и т.п.), привязка к тегам базы каналов и логика реакции на изменение
значений. Готовая схема сохраняется на сервер и впоследствии открывается для просмотра
в режиме **«Монитор»**.

Работа организована в иерархии **Проект → Схема (сцена) → Элементы**. Схема не может
существовать сама по себе — она всегда принадлежит какому-то проекту.

## 2. Интерфейс редактора

Схематично экран редактора выглядит так:

```
┌───────────────────────────────────────────────────────────────────────┐
│ Редактор схем │ Монитор │ База каналов │ Логирование        (шапка)    │
├───────────────────────────────────────────────────────────────────────┤
│      Проект: ИмяПроекта   Сцена: ИмяСхемы     [панель инструментов]    │
├──────────┬────────────────────────────────────────────────┬───────────┤
│ Палитра/ │  Редактор │ Рецепты │ ... │ Справка   (вкладки)  │           │
│  Слои    ├────────────────────────────────────────────────┤ Свойства  │
│          │                                                │ выбранного│
│ (левая   │                    Х О Л С Т                    │ элемента  │
│ панель)  │           (сетка 20 px, зум 20–300%)             │ (правая   │
│          │                                                │  панель)  │
│          │                                        [ − 100% + ⤢ ↺ ]    │
└──────────┴────────────────────────────────────────────────┴───────────┘
```

- **Левая панель** — две вкладки: **«Палитра»** (набор элементов для перетаскивания) и
  **«Слои»** (дерево объектов текущей схемы). Сворачивается стрелкой на правом краю панели.
- **Центр** — вкладки рабочей области (по умолчанию открыта «Редактор» с холстом) и сам холст.
- **Правая панель** — свойства выбранного элемента (или нескольких, если выделено больше
  одного). Сворачивается аналогично левой.
- **Плавающая панель инструментов** сверху по центру — название текущих проекта/схемы,
  кнопки работы с проектом/схемой, группировка, выравнивание, сохранение.
- **Панель масштаба** — в правом нижнем углу холста.

## 3. Проекты и схемы

Кнопки в панели инструментов (слева направо):

| Кнопка | Действие |
|---|---|
| 💼 «Проект» | Открыть список проектов, выбрать существующий или создать новый по имени. После выбора сразу открывается список схем проекта. |
| 📄+ «Создать сцену» | Создать новую пустую схему в текущем проекте. |
| 📂 «Загрузить сцену» | Показать список схем текущего проекта — выбрать для загрузки, создать новую или удалить схему из списка (крестик рядом с именем). |
| ⬆ «Импорт» | Загрузить элементы из JSON-файла и добавить их в текущую схему. Координаты в файле могут быть в пикселях или в процентах от размера холста (5000×5000). |
| 💾 «Сохранить» | Сохранить схему на сервер. |

**Важно:**

- Пока не выбран проект, кнопки «Создать сцену» и «Загрузить сцену» сами предложат сначала
  выбрать/создать проект.
- Если открытая схема не относится к выбранному проекту, под панелью инструментов появится
  предупреждение «Сцена не принадлежит проекту «…»», а операции редактирования (группировка,
  импорт, сохранение, выравнивание) будут недоступны — нужно загрузить схему именно из списка
  текущего проекта.
- **Автосохранение**: схема с изменениями сохраняется автоматически раз в минуту без
  уведомлений и без сброса текущего выделения. Кнопка «Сохранить» по-прежнему работает как
  ручное сохранение «прямо сейчас» (с уведомлением об успехе/ошибке).
- Удаление схемы из списка («Загрузить сцену» → крестик) необратимо — появится
  подтверждающий вопрос.

## 4. Работа с холстом

### Навигация

| Действие | Как выполнить |
|---|---|
| Панорамирование (сдвиг вида) | Колесо мыши — вертикально; Shift + колесо — горизонтально; либо зажать среднюю кнопку мыши и тащить. |
| Масштабирование | Ctrl + колесо мыши (масштаб идёт «к курсору»), либо кнопки −/+ в панели масштаба в правом нижнем углу. |
| Вписать схему в экран | Кнопка ⤢ в панели масштаба. |
| Сбросить масштаб на 100% | Кнопка ↺ в панели масштаба. |

Масштаб ограничен диапазоном 20–300%.

### Сетка и привязка

Все элементы выравниваются по сетке с шагом **20 пикселей**: при перетаскивании, изменении
размера и вводе координат значения автоматически округляются до ближайшего кратного 20.
Это удобно держать в уме при точной подгонке элементов друг к другу.

При перетаскивании элемент также **магнитится** к краям и центрам соседних фигур того же
уровня (подсвечивается тонкой пунктирной линией) — это помогает выровнять элементы «на глаз».

### Выделение

| Действие | Как выполнить |
|---|---|
| Выделить один элемент | Клик по нему. |
| Добавить элемент к выделению / снять его | Shift+клик или Ctrl+клик. |
| Выделить рамкой (маркизом) | Зажать кнопку мыши на пустом месте холста и потянуть. В выделение попадают только элементы **текущего уровня** (если вы внутри группы — только элементы этой группы, а не вся схема). |
| Выделить всё на текущем уровне | Ctrl+A. |
| Снять выделение / выйти из группы | Esc. |

При наведении курсора на элемент (без клика) он подсвечивается пунктирной рамкой — это
показывает, что именно будет выбрано по клику. Если элемент — часть группы, подсвечивается
рамка всей группы: так сразу видно, что элементы объединены.

## 5. Добавление элементов

Элементы добавляются перетаскиванием из **палитры** (левая панель, вкладка «Палитра») на
холст. В палитре есть поиск по названию (при поиске все категории раскрываются
автоматически) и группировка по категориям, которые можно сворачивать/разворачивать.

Категории и элементы «из коробки»:

### Базовые

| Элемент | Назначение | Настраиваемые параметры |
|---|---|---|
| Линия | Прямая линия/связь между узлами | Цвет, толщина, стиль (сплошная/пунктир/штрих-пунктир), стрелка на конце |
| Круг | Простая геометрическая фигура | Радиус, цвет заливки, цвет и толщина обводки |
| Многоугольник | Фигура с произвольным числом углов | Количество углов, цвет заливки, цвет и толщина обводки |
| Текст | Надпись | Содержимое, размер шрифта, цвет, выравнивание, жирность |
| Картинка | Изображение | При перетаскивании на холст сразу открывается проводник для выбора файла; вписывание — «по размеру» / «с обрезкой» / «растянуть» |
| Прогресс-бар | Индикатор заполнения | Значение (%), ориентация (гориз./верт.), заголовок, цвет полосы/фона/рамки/текста, показ процентов |
| Чекбокс | Флажок вкл/выкл | Состояние, подпись, цвет при отметке, цвет фона/рамки/текста |

### Управление

| Элемент | Назначение | Настраиваемые параметры |
|---|---|---|
| Кнопка | Кнопка нажатия | Текст, цвет фона/текста, скругление углов, признак «активна» |
| Тумблер | Переключатель вкл/выкл | Состояние, подпись, цвет вкл/выкл, цвет текста |
| Слайдер | Ползунок значения | Значение, минимум, максимум, цвет заполнения/трека |
| Выпадающий список | Список выбора | Текущее значение, цвет фона/рамки/текста |
| Поле ввода | Текстовое поле | Значение, подсказка, цвет фона/рамки/текста |

### Визуализация

| Элемент | Назначение | Настраиваемые параметры |
|---|---|---|
| Гаус (круговой индикатор) | Стрелочная шкала значения | Значение, мин/макс, единица измерения, точность, цвета стрелки/фона/шкалы/текста, показ значения, углы начала/конца дуги |
| Таблица | Табличный блок | Число строк/столбцов, заголовок, цвета, размер шрифта, чередование строк |
| Тренды | График изменения значения во времени | Заголовок, цвет линии/фона/рамки/сетки/текста, сетка, точки данных, заливка под линией, границы оси Y |
| График | Столбчатый/линейный/областной график | Заголовок, тип (столбцы/линия/область), ориентация, цвета, сетка, подписи значений |

Помимо этого списка, в палитре могут появляться **пользовательские шаблоны** (см.
[раздел 13](#13-сохранение-своих-элементов-в-палитру)) — они складываются в свою категорию
и удаляются кнопкой корзины при наведении (в отличие от элементов «из коробки», которые
удалить нельзя).

## 6. Перемещение, размер, поворот

- **Перетаскивание** — зажать элемент и потянуть; позиция привязывается к сетке.
- **Изменение размера** — у выделенного прямоугольного элемента появляются 8 маркеров по
  контуру (тянуть за угол — пропорции не сохраняются; за сторону — меняется одна ось).
  У линии, круга, текста, многоугольника и группы — свои собственные ручки изменения формы.
- **Поворот** — доступен для «прямоугольных» элементов через отдельный маркер вращения
  (кроме групп — у них поворота нет).
- **Точный ввод координат** — в панели свойств справа, вкладка «Визуал» → блок «Геометрия»:
  X, Y, Ширина, Высота, Поворот (°). У линии вместо этого — X1/Y1 и X2/Y2 (координаты
  начала и конца). Координаты X/Y отсчитываются **от родительского контейнера** (для
  элемента внутри группы — от угла группы, а не от угла всей схемы).
- **Сдвиг стрелками клавиатуры** — на шаг сетки (20 px); с зажатым Shift — на 1 px, для
  точной подгонки.
- **Копирование/вставка** — Ctrl+C / Ctrl+V; вставленная копия сдвигается немного вправо-вниз
  от оригинала.
- **Дублирование** — Ctrl+D (аналог копировать+вставить одной клавишей).

## 7. Выравнивание и распределение

При выделении **двух и более** элементов в панели инструментов становятся доступны кнопки
выравнивания:

- по левому / правому краю, по центру по горизонтали;
- по верхнему / нижнему краю, по центру по вертикали.

При выделении **трёх и более** элементов дополнительно доступно равномерное распределение
по горизонтали и по вертикали (равные промежутки между элементами).

## 8. Порядок наложения элементов

Через **правый клик по элементу** → пункты контекстного меню:

- **«На передний план»** — вывести элемент поверх остальных;
- **«На задний план»** — увести элемент под остальные.

Внутри группы/компонента порядок задаётся так же, но действует только среди «соседей» на
том же уровне вложенности.

## 9. Группы и компоненты

Важно различать два похожих, но разных понятия:

- **Группа** — простое визуальное объединение нескольких элементов, чтобы перемещать,
  копировать и выделять их как единое целое. Ничего больше группа не даёт.
- **Компонент** — «полноценный» функциональный узел схемы: у него есть свои
  [состояния](#11-панель-свойств-элемента) («Норма» / «Авария» и т.п.), к нему можно
  привязать теги, скрипты и логику реакции на данные, а также сохранить его как шаблон в
  палитру для переиспользования на других схемах.

Действия (панель инструментов и правый клик по элементу):

| Действие | Где | Что делает |
|---|---|---|
| Сгруппировать (Ctrl+G) | Панель инструментов, доступно при ≥2 выделенных | Объединяет выделенные элементы в простую группу. |
| Разгруппировать (Ctrl+Shift+G) | Панель инструментов | Полностью распускает группу **или компонент** — все члены поднимаются на уровень выше, сам контейнер исчезает. |
| «Создать компонент» | Правый клик по простой группе | Превращает группу в компонент (не удаляя и не перемещая её содержимое). |
| «Разобрать компонент» | Правый клик по компоненту | Обратное действие: компонент становится обратно простой группой (сам контейнер и его содержимое остаются на месте, просто теряют статус «компонента»). |
| «Добавить компонент» | Правый клик по компоненту | Вложить другой существующий компонент схемы внутрь текущего. |
| «Переместить в группу» | Правый клик по любому элементу | Переместить элемент в выбранную из списка группу/компонент. |

**Как войти внутрь группы/компонента**: двойной клик по нему на холсте или в панели
«Слои». Пока вы внутри, клики и рамка выделения работают только с содержимым этого
контейнера. **Esc** — выйти на уровень выше (повторные Esc — выйти до самого верха).

## 10. Панель «Слои»

Вкладка «Слои» левой панели показывает дерево объектов текущей схемы (только корневые
элементы схемы и их вложенность — «примитивы», из которых собран компонент, показаны
приглушённым цветом текста).

- Клик по строке — выделить элемент; Ctrl/Shift+клик — добавить к выделению.
- Двойной клик по группе/компоненту — войти внутрь (как и на холсте).
- Стрелка слева от строки — свернуть/развернуть вложенное содержимое.
- Иконка компонента (кубики) отличается от иконки простой группы (папка) — так по дереву
  сразу видно, что́ является функциональным компонентом, а что — просто визуальной группой.

## 11. Панель свойств элемента

Появляется в правой панели при выборе одного элемента, состоит из пяти вкладок.

### Визуал

- Блок «Геометрия» — точные X/Y/Ширина/Высота/Поворот (или X1/Y1/X2/Y2 для линии), см.
  [раздел 6](#6-перемещение-размер-поворот).
- Остальные параметры оформления — свои для каждого типа элемента (см. таблицы в
  [разделе 5](#5-добавление-элементов)): цвета, текст, значения, флажки и т.п.

### Состояния

Компонент может иметь несколько именованных **состояний** (например, «Нормальное» и
«Авария») — у каждого своя настройка внешнего вида (цвет, текст и т.д.), заданная в
вкладке «Визуал». Выпадающий список «Состояние:» переключает, какое состояние вы сейчас
редактируете. Кнопка «Добавить состояние» создаёт новое состояние по вводимому названию.

Смена состояния распространяется на весь компонент целиком по имени состояния: если
компонент собран из нескольких элементов и у всех есть состояние «Авария», переключение
затронет их разом. Именно эти состояния переключаются автоматически в режиме «Монитор» по
логике [привязок](#привязки).

### Свойства

Здесь элемент **привязывается к тегу базы каналов** (или заводится как отдельное свойство,
не связанное с тегом). Кнопка «Добавить свойство» открывает форму:

- **Название**, **Описание**, **Тип значения** (произвольная строка вроде
  `string`/`number`/`boolean`), **Значение по умолчанию**, флажок **«Логирование»**,
  поле **onChange** (описание/код обработчика изменения);
- **Тип свойства**: «Тег» (требует выбрать тег в дереве устройств прямо в этой форме),
  «Глобальный» или «Локальный» (без привязки к тегу).

Уже добавленные свойства показаны бирками под заголовком «Добавленные свойства» — клик по
бирке открывает её на редактирование.

**Удаление свойства** — корзина на бирке либо кнопка «Удалить свойство» в форме редактирования.
Перед удалением появится подтверждение со списком того, что на это свойство ссылается. Важные
особенности:

- удаление уходит на сервер **сразу** и **не отменяется** Ctrl+Z (как и создание свойства);
- прямые привязки (созданные кнопкой «Привязать свойство») удаляются целиком — без ссылки они
  нерабочие; из привязок-скриптов и обработчиков событий убирается только ссылка, а код остаётся —
  его нужно поправить вручную;
- если у элемента останутся привязки, но ни одного сохранённого свойства, схема перестанет
  сохраняться, пока вы не добавите свойство заново или не удалите привязки — об этом диалог
  предупреждает отдельной красной строкой;
- если схему в это время успел сохранить кто-то другой, удаление отклоняется — обновите схему и
  повторите.

**Ограничение:** кнопка «Добавить свойство» неактивна, если

1. элемент ещё не сохранён на сервере (сначала сохраните схему кнопкой «Сохранить»), **и/или**
2. не загружено дерево устройств — зайдите в раздел «База каналов» и загрузите нужный
   проект устройств, затем вернитесь в редактор.

Подсказка под кнопкой поясняет, какое из условий не выполнено.

### Скрипты

Кнопка «Добавить скрипт» открывает редактор кода (Java) с полями «Название скрипта» и
«Код скрипта». Скрипт хранится вместе со схемой и относится к серверной обработке событий
элемента. Уже добавленные скрипты показаны бирками — клик открывает редактирование.

### Привязки

**JavaScript-логика, которая выполняется на клиенте в режиме «Монитор»** при изменении
значений тегов: переключает состояние компонента или меняет визуальные свойства элемента.

Кнопка «Добавить привязку» открывает редактор кода, в котором:

- в области кода доступны теги элемента как объекты с полями `.V` (значение) — клик по
  бирке тега вставляет `ИмяТега.V` в позицию курсора;
- клик по бирке состояния вставляет вызов `setState("ИмяСостояния")`;
- доступна функция `setProp("ключ", значение)` для изменения визуального свойства;
- есть **тест-прогон**: ввести подставные значения тегов и нажать «Выполнить» — редактор
  покажет, какие `setState`/`setProp` вызовет код, не заходя в реальный монитор.

Список уже созданных привязок показан в виде строк с переключателем «включена/выключена»,
кнопками редактирования и удаления.

**Важное ограничение:** привязку нельзя сохранить, если у элемента ещё нет **своего
сохранённого свойства с типом «Тег»** (см. вкладку «Свойства» выше) — сервер в этом случае
отклонит сохранение **всей схемы целиком**, а не только этой привязки. Сначала добавьте
элементу хотя бы одно свойство-тег, затем создавайте привязки.

## 12. Редактирование нескольких элементов сразу

При выделении **двух и более** элементов правая панель показывает общие для всех выбранных
типов элементов свойства — изменение значения применяется сразу ко всем выделенным одним
действием (отменяется/повторяется тоже одним шагом Ctrl+Z/Ctrl+Y).

## 13. Сохранение своих элементов в палитру

Любую группу или компонент можно сохранить как переиспользуемый шаблон: правый клик по
ней → **«Сохранить в палитру»**. Откроется окно:

- **«Создать новый»** — ввести название и категорию шаблона (категория станет разделом
  палитры, где он появится);
- **«Обновить существующий»** — выбрать один из ранее сохранённых пользовательских
  шаблонов и перезаписать его текущим содержимым группы/компонента.

После сохранения шаблон появляется в палитре (обычно внизу списка, в своей категории) и
перетаскивается на холст так же, как элементы «из коробки». В отличие от встроенных
элементов, пользовательские шаблоны можно удалить (иконка корзины при наведении на элемент
палитры) или удалить сразу всей категорией (иконка корзины у заголовка категории).

## 14. Отмена и повтор действий

- **Ctrl+Z** — отменить последнее действие;
- **Ctrl+Shift+Z** или **Ctrl+Y** — повторить отменённое действие.

История отмены хранит до 50 последних изменений схемы и **не переносится** между разными
схемами/проектами — при переключении на другую схему история отмены обнуляется.

## 15. Горячие клавиши

| Клавиши | Действие |
|---|---|
| Esc | Снять выделение / выйти из группы на уровень выше |
| Delete / Backspace | Удалить выделенные элементы |
| Ctrl+C | Копировать |
| Ctrl+V | Вставить |
| Ctrl+D | Дублировать |
| Ctrl+A | Выделить все элементы текущего уровня |
| Ctrl+G | Сгруппировать выделенное |
| Ctrl+Shift+G | Разгруппировать |
| Ctrl+Z | Отменить |
| Ctrl+Shift+Z / Ctrl+Y | Повторить |
| Стрелки ← ↑ → ↓ | Сдвинуть выделенное на шаг сетки (20 px) |
| Shift + стрелки | Сдвинуть выделенное на 1 px |
| Двойной клик по группе/компоненту | Войти внутрь |
| Двойной клик по тексту | Редактировать текст на месте (Esc или клик вне поля — сохранить) |
| Правая кнопка мыши | Контекстное меню элемента (или «Вставить» на пустом месте) |
| Средняя кнопка мыши + перетаскивание | Панорамирование холста |
| Колесо мыши / Shift+колесо | Панорамирование по вертикали / по горизонтали |
| Ctrl + колесо мыши | Масштабирование к курсору |

Горячие клавиши не срабатывают, пока курсор находится в текстовом поле ввода (например,
при вводе координат или названия свойства) — это защищает от случайных действий во время
набора текста.

## 16. Прочие вкладки рабочей области

Помимо вкладки «Редактор» (холст), в верхней полосе вкладок рабочей области есть ещё:
«Рецепты», «Параметры линии», «Параметры станции», «ПИД регулятор», «Обвязка линии»,
«Сигналы», «Журнал аварий», «Отчёты», «Справка». На момент этого руководства эти вкладки
зарезервированы под будущий функционал и не содержат рабочих инструментов — используйте
основную вкладку «Редактор».

## 17. Частые ограничения и что с ними делать

| Симптом | Причина | Что делать |
|---|---|---|
| Все кнопки редактирования в панели инструментов серые (недоступны) | Открытая схема не принадлежит выбранному проекту | Открыть «Загрузить сцену» и выбрать схему из списка текущего проекта |
| Кнопка «Добавить свойство» неактивна | Элемент ещё не сохранён на сервере, и/или не загружена база каналов | Сохранить схему; открыть раздел «База каналов» и загрузить нужный проект устройств |
| Кнопка «Сохранить» недоступна во вкладке «Привязки» | У элемента нет собственного сохранённого свойства с типом «Тег» | Сначала добавить элементу свойство-тег во вкладке «Свойства» |
| Изменения не появляются в «Монитор» | Схема с новыми изменениями ещё не сохранена | Дождаться автосохранения (раз в минуту) или нажать «Сохранить» вручную |
| «Разгруппировать» неожиданно удалило компонент целиком, а не просто сняло с него статус | Это ожидаемое поведение: «Разгруппировать» полностью распускает и группы, и компоненты | Чтобы только снять статус «компонента», сохранив содержимое сгруппированным, используйте «Разобрать компонент» из контекстного меню |
