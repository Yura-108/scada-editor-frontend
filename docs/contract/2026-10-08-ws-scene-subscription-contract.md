# WS монитора: изменения тегов только по открытой сцене

Дата: 08.10.2026. Задача бэкенда: scada-w0rt.6. Бэкенд готов (ветка `dev`, коммит `aa84407`),
фронт — по этому контракту.

## Зачем

Сейчас каждая сессия монитора получает в `UPDATE.tags` изменения **всех** тегов проекта, хотя на
экране одна сцена. Нагрузочный прогон 05.10.2026 (20 проектов, 200 сессий): ~16 МБ/с трафика WS и
2,1 ядра runtime на сериализацию. Подписка на сцену режет поток до тегов открытой сцены.

## Протокол

Фронт → runtime, по тому же WS, что `ACTION` и `SUBSCRIBE_TASKS`:

```json
{"type": "SUBSCRIBE_SCENE", "sceneId": 10556}
{"type": "SUBSCRIBE_SCENE", "sceneId": 10556, "tags": ["Барановичи-1.BN1_MCA1.TANK1LT1.CLEVEL"]}
{"type": "UNSUBSCRIBE_SCENE"}
```

- `sceneId` — id компонента-сцены (`type: "scene"`) текущего выпуска.
- `tags` — необязательно: пути тегов, которые экран показывает **вне** сцены (инспектор объектов,
  открытый фейсплейт чужого объекта, легенда тренда с тегом не со сцены). Подписка заменяет прежнюю
  целиком — при открытии/закрытии такой панели присылать `SUBSCRIBE_SCENE` заново с новым списком.
- `UNSUBSCRIBE_SCENE` — снова все теги проекта.

## Что делает runtime

1. Дальше в `UPDATE.tags` этой сессии — только теги поддерева сцены (объекты, их дети, примитивы групп)
   плюс `tags`.
2. **Сразу** кладёт в ближайший `UPDATE` текущие значения тегов сцены: пока монитор смотрел другую
   сцену, их изменения не приходили, и на экране остались бы старые значения. Отдельного `SNAPSHOT`
   нет — значения приходят обычным `UPDATE`.
3. Неизвестная сцена — подписка на пустой набор (плюс `tags`), в лог runtime `WARN`.
4. **Смена выпуска** (`TREE_CHANGED`) снимает подписку: сцены нового выпуска могут состоять из других
   тегов. После `TREE_CHANGED` и `SNAPSHOT` фронт присылает `SUBSCRIBE_SCENE` заново.
5. Без подписки всё как раньше — все теги проекта. Старый фронт работает без изменений.

Свойства (`UPDATE.properties`), процедуры, задачи и `SNAPSHOT` при подключении подпиской не
фильтруются.

## Что сделать во фронте

- При открытии сцены в мониторе (и при переключении сцен) — `SUBSCRIBE_SCENE` с её id.
- После каждого `TREE_CHANGED` — повторить `SUBSCRIBE_SCENE` для текущей сцены.
- Панели, показывающие теги не со сцены, — добавлять их пути в `tags`.
- Режим «Архив» (воспроизведение) живой поток не использует — подписка не нужна.
