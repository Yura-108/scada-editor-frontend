# `image` проекта (общие закрепления схем) — ответ бэка (30.09.2026)

Ответ на `fromFront/2026-09-30-project-image-contract.md`. **Контракт принят как есть**: путь, тело,
ответы и признак «поле есть — бэк новый» совпадают с запросом. Менять на фронте ничего не нужно.
Бэкенд — ветка `fix/action-read-tag` (пока не в `main`).

## Что совпало

| | |
|---|---|
| Чтение | `GET /api/editor/components/projects` → `[{id, name, image}]`; `image` — объект или `null`, поле есть всегда |
| Запись | `PUT /api/editor/projects/{projectId}/image` `{"image": {...}}` → `200 {"image": {...}}` |
| Семантика | Объект заменяет хранимый целиком, последняя запись побеждает; содержимое бэк не разбирает |
| Версии и выпуски | Не создаются; в снимок выпуска не входит; `TREE_CHANGED` не вызывает |
| Ошибки | `404` — проекта нет (или id не проекта); `400` — `image` не объект или его нет в теле |

## Чем отличается от запроса

- **Хранится не в состоянии проекта**, а в отдельной колонке `editor.project_runtime.image`. Причина:
  выпуск — это всё дерево проекта вместе с его `states`, и `image` в состоянии попал бы в каждый
  выпуск. Для фронта разницы нет, но **в `GET /api/editor/components/{projectId}` и в дереве
  выпуска этого `image` нет** — читать только из списка проектов.
- **Предел 16 КБ** на сериализованный объект, больше — `400`. Закреплениям этого хватает с запасом.
- **Запись любого ключа — любым пользователем.** gateway отличает только «есть токен / нет»,
  редактор от монитора на бэке не отличить. Запрет на запись из монитора — на фронте, как у вас и
  написано.

## На что обратить внимание

- **Гонка.** Перечитать и заменить — не атомарно: два инженера закрепили в одну секунду — одна
  правка потеряна. Пока ключ один (`pinnedScenes`), это приемлемо. Если в `image` появятся другие
  ключи, которые правят часто, — скажите, сделаем запись по ключу на бэке.
- **Перенос из localStorage.** Закрепления проекта получит тот, кто первым откроет его в редакторе;
  остальные локальные наборы не перенесутся. Если так и задумано — ок.
- Id удалённых схем бэк из `ids` не чистит — как вы и просили.
