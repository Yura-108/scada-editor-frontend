# Инструкции для агентов

Перед изменениями прочитайте [правила Git](CONTRIBUTING.md) и [соглашения фронтенда](CLAUDE.md). Они действуют во всём репозитории. Соседний репозиторий бэкенда доступен только для чтения.

Каждый новый блок работы начинайте в отдельной ветке от актуальной `origin/dev`. Перед PR выполните `npm run check:pr` и проверки из CONTRIBUTING.md. Завершите блок PR в `dev` и передайте пользователю ссылку и результаты. Если проверка или публикация заблокирована, укажите конкретную причину. Решение о слиянии принимает ответственный за фронтенд.
